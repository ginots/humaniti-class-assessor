# HUMANITI · Class Evidence

Local MP4 → browser transcription → de-identification and review → text-only Gemini assessment → timestamped report. Python 3.14 and vanilla JavaScript; no frontend build tools.

## Start

```powershell
Set-Location E:\HumanitiAI\app
.\scripts\start.ps1
```

Open **http://127.0.0.1:8000** in current desktop Chrome/Edge. The E: environment and public model assets are prepared. The start script starts a detached server or reuses the running application. Closing its launching terminal does not stop a newly detached server. To stop it, use `Stop-Process -Id <the printed process ID>`. Startup checks verify readiness; server errors stay under `E:\HumanitiAI\tmp` without request/response body logging.

Use an AI Studio project with billing disabled and `GEMINI_MODEL=gemini-3.8-flash`. python-dotenv loads the server key; environment variables take precedence. Configuration checks print booleans only. The application never enables billing, automatically retries quota failures, or silently selects another model. It cannot inspect project billing status.

## How it works

1. **Local media:** Mediabunny lazily reads the selected MP4. A worker downmixes/resamples decoded frames into 30-second, 16 kHz windows for local Whisper tiny inference. One decoded waveform is about 1.92 MB; no hour-long PCM buffer is created. Progress and cancellation keep the interface usable.
2. **Local review:** VTT import retains cue times and converts explicit voice labels to generic speaker IDs. Automatic replacements cover common contact identifiers, introduction names and user-supplied private terms. Edit the segments and confirm review. Changes invalidate confirmation and previous reports. Redaction is incomplete: inspect names, schools, locations and indirect identifiers. Whisper does not identify speakers.
3. **Text-only API:** The backend accepts only review flags, anonymous timestamped segments, coverage and speaker reliability. It rejects media, original filenames, maps, labels, raw VTT, extra fields and obvious contact identifiers. This contract cannot prove semantic de-identification; human review remains essential. Bodies are neither logged nor persisted.
4. **Evidence first:** Gemini JSON mode supplies exact quotes, observations, interpretations and specific improvements; a JSON contract is included in its system instruction. The richer provider schema was rejected or timed out in this project, so strict validation is performed on the backend. The server checks quotes, references, timestamps and scores before deriving the category. Missing evidence is unobserved; errors and insufficient input produce no invented rating.

Four equally weighted dimensions assess explanation/structure, checking understanding, feedback/adaptation and participation opportunities. Observed scores are 0–3; the mean rounds half up to Poor/Average/Good/Excellent. A rating requires three observed dimensions and four validated evidence items. Excellent requires all four dimensions observed and none below 2. These prototype thresholds are explicit, not empirically calibrated. Homework, branding or any single behavior is not mandatory.

## Checks and limitations

```powershell
& E:\HumanitiAI\venvs\humaniti\Scripts\python.exe -m unittest discover -s tests
# ONE external request containing synthetic lesson text only:
& E:\HumanitiAI\venvs\humaniti\Scripts\python.exe .\scripts\check_gemini.py
```

Python tests: 51 passed, one existing Windows symlink-permission skip (52 total). Synthetic browser checks verified VTT timing, generic speaker labels, identifier removal and payload fields. Both MP4 and VTT paths completed live reviewed-text-to-report workflows. A generated 31.7-second AAC MP4 produced five segments across two windows. Network inspection included 14 worker asset requests, with zero external browser requests; assessment POSTs contained only approved text fields. Cancellation and consent/report reset passed. A heuristic also rejects common unsupported visual/vocal claims; provenance checks do not prove every interpretation correct.

The optional synthetic video button uses a fixture generated by `scripts\make_synthetic_video.ps1`. All fixture media/tools remain outside Git on E:. Automated browser checks use `scripts/browser_check.py`, websocket-client 1.9.0 in a separate E: test environment, and isolated headless Chrome.

CPU/WASM short-video transcription is verified. WebGPU, Hindi, hour-long throughput and human-rating agreement remain unmeasured. Tiny-model accuracy, simple resampling, chunk boundaries, missing diarization and manual redaction limit reliability. Visual presentation, emotion and vocal qualities are unassessed. Partial/unknown coverage cannot prove activities absent.

## Deployment preparation

The Dockerfile stages only application code and pinned public browser assets. Set server secrets `GEMINI_API_KEY`, `GEMINI_MODEL`, and a random `APP_ACCESS_TOKEN`; configure the host's `PORT`. Public binding requires the token. Use HTTPS, preserve CSP/isolation headers, and allow up to 195 seconds for assessment requests. Do not mount private data or enable body logging. The Docker image and hosted environment still need validation; avoid local Docker image downloads until its storage location is confirmed on E:. Nothing is published or deployed.

Assets are served from the application origin with `connect-src 'self'` and no-store responses. Pins: Transformers.js 3.8.1, Mediabunny 1.62.1, upstream ONNX runtime 1.22.0-dev.20250409-89f8206ba4, Whisper tiny revision `5332fcc35e32a33b86612b9a57a89be7906102b1`. [ASR API](https://huggingface.co/docs/transformers.js/v3.8.1/api/pipelines), [media API](https://mediabunny.dev/guide/media-sinks), [Gemini structured output](https://ai.google.dev/gemini-api/docs/structured-output).

The inventory, original ZIP and private files are preserved. All 12 pairs now resolve using private parent-folder/prefix conventions. Weak maps to Poor; demo and quality-issue examples remain references. Labels/names never enter assessor requests. Feedback informed rubric design, so evaluation on those examples is development/reference-set evaluation, not an untouched independent test.
